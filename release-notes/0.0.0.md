# Singalong Desktop development checkpoint

This is an implementation checkpoint, not a stable compatibility or release claim. Testing is currently deferred.

Source includes Windows media-session allowlisting, sticky selection and waiting pins; shared provider lookup and offline lyrics; main and floating readers with modes, supplied word emphasis, optional estimates and timing corrections; local library search/favourites; manual search/correction; backup import/export and merge restore; opt-in startup, manual updates and reviewed diagnostics.

Playback information depends on the media sessions each player/browser exposes. Stream pinning is offered only when identity is reliable. Missing position remains manual reading. Automatic floating display and Windows sign-in startup are separate opt-ins.

The verification, backup migration, installer/upgrade, dependency-license and signing gates must pass before publication. No automatic updater is included. The product/download landing page is separate future work.
